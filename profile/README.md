### ⚡ Quickstart

Scaffold a production-ready Android app in seconds:

```bash
bun create jilatax@latest
# or: npm create jilatax@latest | pnpm create jilatax@latest | yarn create jilatax@latest
```

---

### 🌟 Features

- 🤖 **Android-First**: Optimized runtime for native Android apps.
- ⚡ **Zero Config**: One command setup — the CLI wires the rest.
- 🏎️ **Lynx & Rspeedy**: Native UI rendering with React & CSS skills.
